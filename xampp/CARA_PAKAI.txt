=====================================================================
  APLIKASI PENGINGAT HARI JADI DAERAH PEMEGANG SAHAM - VERSI XAMPP
=====================================================================

Aplikasi ini mengirim pengingat otomatis 7 hari sebelum (H-7) hari jadi
setiap daerah pemegang saham, lewat WhatsApp, Telegram, dan Email.
Data cukup diisi SEKALI (nama daerah + tanggal hari jadi); pengingat
berulang sendiri setiap tahun pada tanggal yang sama. Data baru tetap
bisa ditambah kapan saja.

PENTING
- Aplikasi berjalan di laptop/komputer kantor (XAMPP). Pengingat hanya
  terkirim jika komputer menyala. Jika komputer mati tepat di hari H-7,
  pengingat dikirim begitu komputer menyala lagi (selama belum lewat
  hari H), jadi tidak ada yang terlewat.
- Pengingat tiap daerah hanya dikirim 1x per tahun (tidak dobel).

---------------------------------------------------------------------
1. PASANG
---------------------------------------------------------------------
1) Pindahkan folder "pengingat-hari-jadi" ke  C:\xampp\htdocs\
   (atau D:\xampp\htdocs\ sesuai lokasi XAMPP).
   Hasilnya: C:\xampp\htdocs\pengingat-hari-jadi\login.php
2) Buka XAMPP Control Panel -> START Apache dan MySQL.
3) Klik 2x  pengingat-hari-jadi\database\import_database.bat
   (membuat database "pengingat_hari_jadi" + file pengaturan .env).
4) Buka browser: http://localhost/pengingat-hari-jadi/
   Pertama kali akan muncul halaman "Buat Akun Admin". Isi, lalu login.
   Akun lain dibuat lewat menu User.

---------------------------------------------------------------------
2. PENGATURAN (file .env di folder pengingat-hari-jadi)
---------------------------------------------------------------------
Buka file .env dengan Notepad, isi:
  FONNTE_TOKEN=        token device dari dashboard fonnte.com (WhatsApp)
  TELEGRAM_BOT_TOKEN=  token bot dari @BotFather (Telegram, gratis)
  SMTP_USER=           alamat Gmail pengirim
  SMTP_PASS=           App Password Gmail (BUKAN password biasa). Buat di
                       myaccount.google.com/apppasswords (wajib Verifikasi 2 Langkah)
Lainnya:
  NOTIF_VIA=wa,telegram,email   saluran yang dipakai (hapus yang tidak perlu)
  PENGINGAT_HARI=7              ganti angka bila ingin H-3, H-14, dll.
  DB_PASSWORD=                  isi jika MySQL XAMPP memakai password
File .env tidak bisa dibuka dari browser (diblokir .htaccess).

---------------------------------------------------------------------
3. MENGISI DATA & PENERIMA
---------------------------------------------------------------------
- Menu Hari Jadi -> "+ Tambah hari jadi": isi
    Nama daerah      : Kota Pekanbaru
    Tanggal hari jadi: 23-06-2026   (yang dipakai tanggal & bulannya,
                                     tahunnya bebas, misalnya tahun ini)
  Pengingat dikirim H-7 setiap tahun pada tanggal yang sama.
- "Tambah banyak": tempel banyak daerah sekaligus, satu per baris
  (nama ; tanggal):
      Kota Pekanbaru;23-06-2026
      Kabupaten Kampar;06-02-2026
  (bisa juga menempel 2 kolom langsung dari Excel)
- Menu Penerima: tambah nomor WhatsApp, chat Telegram, dan alamat email.
  Telegram: minta penerima membuka bot lalu klik Start (di grup:
  kirim /start@nama_bot), lalu klik "Cari chat yang sudah Start bot" -> Tambah.
  Klik "Kirim percobaan" di tiap kotak untuk mengecek pengaturannya.

---------------------------------------------------------------------
4. PENGINGAT OTOMATIS (Windows Task Scheduler)
---------------------------------------------------------------------
Cara mudah: klik 2x  pengingat-hari-jadi\pasang_jadwal.bat
  -> jadwal "Pengingat Hari Jadi" dibuat: setiap hari jam 07.00, setiap
     login Windows, dan langsung jalan saat komputer menyala bila jam
     07.00 terlewat. Jika gagal, klik kanan -> Run as administrator.
Coba manual kapan saja: klik 2x  kirim_pengingat.bat
  (MySQL XAMPP dinyalakan otomatis bila belum jalan)
Hasil setiap pengiriman tersimpan di pengingat_log.txt dan di menu
Riwayat Kirim.

Cara manual (jika pasang_jadwal.bat tidak bisa):
 1) Tombol Windows -> ketik "Task Scheduler" -> buka.
 2) "Create Basic Task..." -> Nama: Pengingat Hari Jadi -> Next
 3) Trigger: Daily -> jam 07:00:00 -> Next
 4) Action: Start a program -> Browse -> pilih
    ...\htdocs\pengingat-hari-jadi\kirim_pengingat.bat , Add arguments: auto
 5) Centang "Open the Properties dialog" -> Finish -> tab Settings ->
    centang "Run task as soon as possible after a scheduled start is missed" -> OK.

---------------------------------------------------------------------
5. JIKA ADA MASALAH
---------------------------------------------------------------------
- "Koneksi database gagal"  -> MySQL di XAMPP belum START, atau
                               import_database.bat belum dijalankan.
- Halaman "Not Found"       -> pastikan foldernya htdocs\pengingat-hari-jadi
- WA tidak terkirim         -> cek FONNTE_TOKEN, internet, status device di
                               fonnte.com. Penyebabnya tertulis di Riwayat Kirim.
- Email gagal               -> pastikan SMTP_PASS berisi App Password Gmail.
- Ingin mengirim ulang      -> pada baris daerah, klik "..." -> pilih
                               "Semua saluran" atau satu saluran saja
                               (WhatsApp / Telegram / Email).
